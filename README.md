# Le Scienze – I Teoremi della Dualità nella Programmazione Lineare

Questo repository contiene le implementazioni in Python, attraverso la libreria open-source [PuLP](https://coin-or.github.io/pulp/), di tutti i modelli matematici di Programmazione Lineare, Programmazione Lineare Intera e Programmazione Lineare Intera Mista degli esempi introdotti nel volume della collana [_RIVOLUZIONI MATEMATICHE. I grandi teoremi da Pitagora a Nash_](https://www.lescienze.it/plus/edicola/collana.jsp?collana=TEOREMI&libreria=LIBRARY) della rivista scientifica di divulgazione [_Le Scienze_](https://www.lescienze.it) dedicato ai teoremi della dualità.
